Execution Flow

The Conversational Turn Lifecycle: Step-by-Step

How a caller's spoken utterance transforms into an intelligent voice response in ~1.5 seconds.
01 • Voice Ingestion

User speaks into microphone. Browser Speech Recognition generates live transcripts and fires turn payload after 600ms pause.

02 • Parallel Context Lookup

Node.js concurrently retrieves Redis session history, embeds query for top-3 RAG chunks, and checks customer phone in ~20ms.

03 • Unified Groq LLM Turn

Single structured prompt to Qwen-27B simultaneously generates spoken reply, intent, sentiment, lead scores, and slot in 500ms.

04 • Conflict & Booking Engine

If booking.slot is parsed, checks MongoDB for double-booking. If free, atomically creates consultation; if taken, offers alternate hour.

05 • Neural Voice Playback

Piper ONNX synthesizes 22,050 Hz speech audio in ~700ms; streams directly to client HTML5 audio element for instant playback.

06 • Memory & Analytics Sync

Appends user and agent utterances to Redis; updates caller lead score in MongoDB. On hangup, auto-summarizes entire dialogue.

Knowledge Retrieval

RAG Architecture & Anti-Hallucination Guardrails

Grounding the conversational model strictly in verified technical specs, pricing, and tax policies.
Vector Ingestion & Retrieval Pipeline
  • Domain Chunking: 10 official solar knowledge documents split into 500-word segments with 80-word overlap for contextual continuity.
  • MongoDB Atlas Vector Search: Hierarchical Navigable Small World (HNSW) index mapping 384-dimensional dense vectors.
  • Hybrid Fallback Engine: If running on local MongoDB without Atlas, dynamically falls back to vectorized cosine scoring in ~18ms.
  • Relevance Truncation: Top 3 most relevant knowledge chunks injected into prompt, keeping token usage under 400 tokens.
Strict Factual Compliance Guardrails
  • Zero-Hallucination Constraint: Prompt strictly prohibits fabricating solar pricing. If unlisted, agent promises specialist follow-up.
  • Deterministic Plan Pricing: Accurately quotes Basic Plan ($99/mo, 5kW), Pro Plan ($199/mo, 10kW + battery), Enterprise ($499/mo).
  • Federal Tax Credit Compliance: Directly quotes the 30% Federal ITC residential clean energy credit accurately without legal liability.
  • Escalation Circuit Breaker: Detects caller frustration or explicit human requests, instantly flagging intent='escalate'.
Engineering Win

The 8.2x Latency Optimization: From 12s to 1.5s

A concrete engineering case study diagnosing and eliminating voice conversation latency.
Bottleneck 1: 120B Model
Before: openai/gpt-oss-120b
9,164 ms per call
After: qwen/qwen3.8-27b on Groq
510 ms per call (18x speedup)

The 120B model generated dozens of internal reasoning tokens before outputting text. Switched to high-throughput 27B model on Groq LPUs.

Bottleneck 2: Dual Roundtrips
Before: Sequential 2x LLM Calls
groq(classify) + groq(reply) = 7.3s
After: Unified Single Turn
Single prompt = 550 ms total

Engineered a unified structured JSON prompt. RAG context is fetched in parallel; single Groq call extracts both reply & lead metadata.

Bottleneck 3: Silence Timeout
Before: Default Silence Wait
2,000 to 3,500 ms wait
After: Tuned VAD Threshold
600 ms auto + Send Now button

Users waited 2-3 seconds in silence after speaking. Reduced pause timeout to 600ms and added instant tap action for immediate dispatch.
